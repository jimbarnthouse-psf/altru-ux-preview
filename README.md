# Altru suggested user flows

Prepared by **Specbee for Altru**, using Altru's existing website design. These suggested flows are provided solely to explore and discuss potential visitor journeys.

- [Start the annotated client walkthrough](https://jimbarnthouse-psf.github.io/altru-ux-preview/review.html)
- [Explore the separate interactive mockup](https://jimbarnthouse-psf.github.io/altru-ux-preview/)
- [Illustrated UX guide - thirteen pages, PDF](https://jimbarnthouse-psf.github.io/altru-ux-preview/Altru-UX-Approach-Guide.pdf)
- [Executive brief - one page, PDF](https://jimbarnthouse-psf.github.io/altru-ux-preview/Altru-UX-Executive-Brief.pdf)

The review offers 11 visitor goals and 47 annotated, prepared screens. Only the outlined guidance links advance the suggested path. Search fields, menus, filters, provider details and maps are static examples; no data entry or live searches are needed. Next, Back, restart and the path chooser remain available. On a phone, notes can collapse for more room. Each path ends with an explanation and a question for review.

The review uses frozen HTML copies of the Altru concept with shared Altru styling and assets. Its screens contain no application scripts, live forms or embedded maps. Their guided links advance to the next prepared screen, including examples of clinical-information and Google Maps handoffs. The separate interactive mockup and both PDFs remain unchanged at their existing links.

The incoming region remains anonymous. Added provider identities, care offerings, relationships and distances are illustrative. Provider practice relationships do not establish local procedure capability. There is no live availability or appointment routing; scheduling remains in MyChart. Production TruSearch configuration and clinical content relationships require Altru's validation.

GitHub Pages publishes the review, its prepared screens and shared assets, the independent original mockup, and the two PDFs from the main branch root.
