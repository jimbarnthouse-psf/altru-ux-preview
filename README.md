# Altru suggested user flows

Prepared by **Specbee for Altru**, using Altru's existing website design. These suggested flows are provided solely to explore and discuss potential visitor journeys.

- [Start the annotated client walkthrough](https://jimbarnthouse-psf.github.io/altru-ux-preview/review.html)
- [Explore the separate interactive mockup](https://jimbarnthouse-psf.github.io/altru-ux-preview/)
- [Illustrated UX guide - thirteen pages, PDF](https://jimbarnthouse-psf.github.io/altru-ux-preview/Altru-UX-Approach-Guide.pdf)
- [Executive brief - one page, PDF](https://jimbarnthouse-psf.github.io/altru-ux-preview/Altru-UX-Executive-Brief.pdf)

The review offers 11 visitor goals and 61 prepared full-site views. A visitor cursor opens the navigation, selects menu links, types search terms, scrolls the page or overlay, and clicks the next action. Menu-led service journeys start before Services is opened; the clinic finder starts with Locations. Explanations remain visible outside the site viewport. Play/Pause, Replay step, Back, Next and restart let a reviewer inspect the sequence, and Desktop/Phone changes the illustrated device. Each path ends with an explanation and a question for review.

The review uses complete frozen HTML copies of the Altru concept with shared Altru styling and assets, including the header, navigation, page content, footer and background behind overlays. The parent player demonstrates visitor behavior; child pages contain no application scripts, live forms or embedded maps. Only guided links advance manually. Clinical-information and Google Maps handoffs are illustrated; the clinical path includes an attributed desktop/phone capture of the existing Altru.org electrophysiology page. No external reference opens automatically in the reviewer’s real browser. The separate interactive mockup and both PDFs retain their existing links and content.

Reduced-motion preference starts journeys paused and removes spatial animation. Reading holds and click feedback remain available. Switching journeys, steps or devices cancels the prior animation. Playback pauses when the document is hidden. Prepared inputs stay inert even while the player illustrates typing; use the separate mockup for free exploration.

The incoming region remains anonymous. Added provider identities, care offerings, relationships and distances are illustrative. Provider practice relationships do not establish local procedure capability. There is no live availability or appointment routing; scheduling remains in MyChart. Production TruSearch configuration and clinical content relationships require Altru's validation.

GitHub Pages publishes the review, its prepared screens and shared assets, the independent original mockup, and the two PDFs from the main branch root.
