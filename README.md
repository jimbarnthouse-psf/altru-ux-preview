# Altru UX preview

Provider, service and location discovery concept prepared by Specbee for Altru.

- [Clickable mockup](https://jimbarnthouse-psf.github.io/altru-ux-preview/)
- [Executive brief - one page, PDF](https://jimbarnthouse-psf.github.io/altru-ux-preview/Altru-UX-Executive-Brief.pdf)
- [Illustrated UX guide - thirteen pages, PDF](https://jimbarnthouse-psf.github.io/altru-ux-preview/Altru-UX-Approach-Guide.pdf)

The unified provider search accepts a name, specialty or clinic, with an optional city/ZIP selector. Services and the clinic finder remain connected experiences. All seven service pages present useful service content and clinical topics before providers and locations. Find a provider is the primary action and opens the matching provider results. Clinical learning links open existing Altru.org pages in new tabs. Heart care locations remain grouped with their illustrative care and delivery details. Other service pages show sample provider practice locations with links to place details and service-filtered teams; they do not assert local treatment capability. Relevant learning resources continue the journey.

The incoming region and its providers remain anonymous or fictional. Care offerings, provider relationships and distances are illustrative. This prototype uses local sample search logic; Altru's production TruSearch configuration still requires validation. Appointment booking remains in MyChart. Google Maps requires internet access.

GitHub Pages publishes the standalone HTML and review PDFs from the main branch root.
